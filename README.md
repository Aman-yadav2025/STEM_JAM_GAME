# Orbit Simulator

A small space-flight game built with React, TypeScript, Vite, and Three.js. Players guide a spacecraft through orbital mechanics, burn planning, and mission objectives across a procedurally styled solar system.

## Features

- 3D space scene with orbiting bodies and trajectory visualization
- Ship controls for thrust direction and throttle
- Physics-driven motion with gravity, orbital transfer logic, and burn planning
- HUD, minimap, codex, and mission briefing UI

## Development

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev
```

Run tests:

```bash
npm test
```

Build for production:

```bash
npm run build
```

## Tech Stack

- React + TypeScript
- Vite
- Three.js / React Three Fiber
- Zustand
- Vitest
